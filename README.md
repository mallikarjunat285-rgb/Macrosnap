# MacroSnap

MacroSnap is an AI-powered vision chatbot that allows users to upload images and interact with them using AI. It helps users understand and analyze image content through natural-language responses.

## Features

- Upload images
- AI-powered image analysis
- Natural-language interaction
- Streamlit web interface
- AI-generated responses

## Tech Stack

- Python
- Streamlit
- Google Gemini API
